# 大戦略ゲーム — HOI4風グランドストラテジー UIシステム

Hearts of Iron IV 風の大規模戦略Webゲーム。Vanilla HTML5 / CSS3 / ES6 Modules（ビルド不要）。

## 起動方法

```bash
# 静的サーバー（リポジトリルートから）
python3 -m http.server 8000
# → http://localhost:8000/hoi4.html          HOI4 単独
# → http://localhost:8000/game/              将軍カードゲーム（H で HOI4 画面）

# マルチプレイ時間同期サーバー（別ターミナル）
node server/timesync-server.js 8787
```

エントリページは **リポジトリルートの `hoi4.html`**。すべてのアセットは厳密なパス
`game/assets/...`・`game/card/...`・`game/locales/ja.json` を参照する。

## 将軍カードゲーム（`game/index.html`）から HOI4 画面を開く

`game/index.html` に **「HOI4 大戦略」全画面レイヤー**を統合済み。カードゲームを
遊びながら、同じタブで HOI4 風の研究・生産・外交・戦闘画面へ切り替えられる。

| 起動方法 | 場所 |
| --- | --- |
| **H キー** | カードゲームのどこからでも（入力欄・IME 変換中を除く） |
| スタート画面 | 「🧭 HOI4 大戦略画面を開く（H）」 |
| 直接 URL | `game/index.html?screen=hoi4`（開いた状態で起動） |

- **Esc** または右上の「閉じる」でカードゲームへ戻る。HOI4 側の上部メニューにも
  「← 将軍カードゲーム」ボタンが出る（`?embed=1` のときだけ）。
- 選択中の国家タグが `?nation=GER` として引き継がれる（`GER/USA/ENG/SOV/JAP/ITA/FRA`）。
- iframe は初回オープンまで読み込まない。閉じても破棄しないため、HOI4 側の
  研究・生産などの状態は保持されたまま即座に再表示できる。
- 閉じている間は HOI4 の時間進行を自動で一時停止する（再表示で再開。
  ユーザーが自分で一時停止していた場合はそのまま）。
- `game/index.html?screen=hoi4` のように URL でも開ける。開閉時は `screen` パラメータだけを
  `history.replaceState` で付け外しする（他のクエリは保持）。

### なぜ iframe なのか

`hoi4.html` は `game/css/steel-ui.css` で `html` / `body` / `button` / `*` などの
グローバルスタイルを所有している。これをカードゲームの DOM に直接読み込むと
既存 UI の CSS を上書きしてしまうため、DOM・CSS・タイマーを完全に分離し、
`postMessage` で可視状態と「戻る」だけを連携している。

| ファイル | 役割 |
| --- | --- |
| `game/hoi4-screen.js` | 全画面レイヤー / 遅延 iframe / H・Esc / inert / URL 同期 / 国家引き継ぎ |
| `game/css/hoi4-screen.css` | スチール調クローム・ローディング・フッター・起動ボタン |
| `game/js/ui/embed.js` | `?embed=1` 時の親ページ連携（可視状態で時間停止 / Esc / ready 通知） |
| `game/js/ui/topbar.js` | 埋め込み時のみ「← 将軍カードゲーム」ボタンをメニュー末尾に追加 |

## 主要システム

- **統一スチールフレームUI**: 全モーダルが金属フレーム＋リベット＋金文字タイトル＋閉じるボタン。
  3D金属ボタン / LEDインジケーター / インセット型入力フィールド。
- **トップバー**: 最上段ステータスバー（国旗Q・政治力・安定度・戦争協力度・徴兵可能人口・
  工場数・燃料残日数・装備充足率LED・輸送船 / 指揮力・陸海空XP・核弾頭）＋2段目メニュー。
- **研究**: `game/eng/tec/data/tech_*.json`（294ノード）を読み込み、国家別補正で独自研究日数を算出。
  Tickでカウントダウン。MIOアサインで研究加速。
- **MIO**: 研究/生産完了でXP蓄積→レベルアップ（最大Lv5）→3段階の特性ツリーを選択。
- **師団設計**: 5×5大隊グリッド＋1×5支援中隊。全ステータスを配置と同時に再計算。
- **兵器設計**: 戦車（車体＋主砲/砲塔/懸架/エンジン/装甲/特殊）、艦艇（船体＋主砲/対空/魚雷/ソナー/
  レーダー/機関/装甲）、航空機（機体＋エンジン/武装/特殊）。
- **増槽（Drop Tank）**: 航続距離+75%〜100% / 機動性-10% / 生産コスト+15%。
  航空機設計タブで装着するとマップ上に出撃可能半径を円表示。
- **戦闘シミュレーター**: 攻撃側/防御側の編成・地形・天候・戦術・指揮官・掘り込みを設定し、
  1Tick（1時間）ごとにダイスロール戦闘。組織力/HPバーのアニメーション＋日本語戦闘ログ。
- **諜報機関**:諜報員カード（`game/assets/operatives/`肖像）を敵国へ派遣。
  「諜報網構築」「暗号解読」「破壊工作」等の任務をタイマー進行。
- **占領地・傀儡国**: 占領度が2週間ごとに+3%。100%で「国家統一」（併合・コア化）ボタン。
- **貿易・6大資源**（`game/index.html` の「貿易」ウィンドウ / `game/assets/trade-resources.js`）:
  石油・鉄・アルミニウム・タングステン・ゴム・クロムの総生産 / 輸入 / 輸出 / 実質利用可能量 / 収支を
  1日あたりで一覧。自国が支配する州の産出合計が基礎生産量になる。
  **民需工場 1 = 資源 8/日**。輸入すると自国の民需工場が相手国の使用枠へ移転 (ロック) され、
  余剰資源を輸出すると相手の民需工場の使用権 (= 民需工場) を獲得する。契約は `strategy.trades` に
  JSON で保存され、セーブ / ロードでも維持される。海上貿易は資源 8/日 ごとに輸送船 1 隻を
  自動割当し、不足すると貿易効率 (= 実効輸入量) が低下。生産ラインは軍需工場ごとに資源を消費し、
  不足すると資源の使用量で重み付けした生産効率ペナルティ (最大 −80%) と赤点滅警告が出る。
- **マルチプレイ時間同期**: HOSTのTickを標準軸に `TIME_SYNC_TICK` を全Clientへ配信。
  一時停止/倍速もブロードキャスト。遅延時はCatch-up補正。
  - 同一ブラウザの別タブ間: BroadcastChannel で同期（サーバ不要）
  - クロスデバイス: PeerJS（`game/index.html` のマルチ画面。ルームコード `HOI4-XXXX`）
- **マルチプレイ・ラウンジ / 時間権限 / チャット / 右クリック外交 / 陣営タブ**
  (`game/assets/multiplayer-hub.js` + `.css`):
  - **ロビー**: ナビの「マルチ」から中央寄せのダークグレー＋金のウィンドウを開く。未接続時は
    「ルームを作成 (ホスト)」と「ルームに参加 (ゲスト)」。作成すると `HOI4-8821` 形式の
    ルームコードを発行し、大きく表示＋ワンクリックでコピー。接続後は
    プレイヤー表 (名前 / 接続状態 / 国旗 / 役割) と国家選択プルダウン、ホスト専用の
    「マルチプレイ開始」(全員が国家を選ぶまで無効) を表示する。
    PeerJS (unpkg) を読み込めない環境では、同じブラウザの別タブと通信する
    BroadcastChannel トランスポートへ自動で切り替わる。
  - **時間権限**: 停止 / 速度 1–5 はホストのみ。ゲストの速度 UI は暗転＋操作不可になり、
    代わりに「⏸ 要請 (Pause Req)」からホストへ一時停止を要求できる。ホストは要求を受けると
    通知ポップアップ＋バナーを出して自動停止する。参戦要請 (Call to Arms)・宣戦布告などの
    外交ポップアップでも時間を自動停止する (ゲスト側はホストへ停止を要求)。
  - **通信状態**: ヘッダー日付の隣に Ping / 同期インジケーター。緑 = 正常 / 黄 = 遅延 /
    赤 = Desync (陣営構造・時間軸のハッシュ不一致)。クリックでマルチ画面、Desync 時は再同期。
  - **チャット**: 左下の半透明パネル。`Enter` で入力欄へフォーカス、`Enter` で送信してフォーカスを外す。
    「全体」「陣営」(同一陣営のみ・秘匿) のタブ、`[国旗][国名/プレイヤー名]: 本文` 表示。
    宣戦布告 / 陣営の創設・加盟 / 一時停止要求 / Desync は
    システムメッセージとして黄・赤で自動記録される。
  - **右クリック外交**: 他国領土を右クリックすると、その場にコンテキストメニューを表示
    (国旗・指導者名・政体・関係値・所属陣営・世界緊張度)。「陣営へ招待」「陣営への加入申請」
    「参戦要請 (Call to Arms)」「政府情報」「外交画面」。政治力不足・非盟主・交戦中・
    民主主義の緊張度制限などは理由付きでグレーアウトする。
  - **陣営タブ**: 政治画面に「陣営」タブを追加。政治力 50 (国家方針で解禁済みなら無料) で
    自由命名の陣営を創設できる。参戦要請は相手が人間プレイヤーなら承諾 / 拒否ポップアップを
    表示し、承諾すると即座に開戦して前線・攻撃線・マップ・チャットを全プレイヤーへ同期する。

- **空軍設計 (BBA) / 海軍設計 (MtG) / 将軍カード割当** (`game/assets/air-naval-design.js` + `.css`):
  - **司令官スロット**: 各航空隊 / 任務部隊カードに「🎖 司令官」スロット。雇用済みの
    `game/card/air` `game/card/navy` カード (エース / 提督 / 司令官) から選択し、パッシブを
    即座に全航空機・全艦艇へ反映する (制空権補正 +15% / CAS 攻撃力 +20% / 全機作戦半径 +100km /
    哨戒発見率 +25% / 潜水艦攻撃力 +30% / 全艦退避速度 +15% など)。
  - **画面の役割分担**: 総合的な装備設計は上部ナビの **「🛠️ 兵器設計」** 画面
    (`game/assets/equipment-designer.js`)。空軍 / 海軍ウィンドウ側は **部隊ごとに採用する設計** と
    **司令官カードの割当** を担当し、設計モーダルの「⚙ 兵器設計を開く」から相互に行き来できる。
  - **BBA 機体設計**: 小型 / 中型 / 大型機体 × エンジン (単発 / 双発 / 4発) ×
    武装 (軽・重機関銃 / 20・30mm 機関砲 / 軽・重爆弾架 / 対戦車機関砲 / 航空魚雷 / 大型爆弾倉) ×
    補助 (防弾装甲 / 自動封鎖式燃料タンク / 落下型増槽 / 対空レーダー / 爆撃照準器 / ダイブブレーカー)。
    エンジン数が速度とペイロード上限を決める。任務はモジュールから自動導出され、
    制空 (機銃) / CAS (爆弾・ダイブブレーカー) / 戦略爆撃 (爆弾倉) / 核攻撃
    (中型・大型機体 + 大型爆弾倉 + 核備蓄 + 目標空域の制空権 75% 以上) が切り替わる。
  - **作戦半径**: 航空隊 / 基地を選択すると、基地を中心に半透明グラデーションの作戦半径円を描画。
    半径は設計の航続距離 (km) から算出し、任務空域が円の外へはみ出した割合に応じて
    任務効率 (実効戦力・CAS ボーナス) が低下する。落下型増槽や長距離型の指揮官で拡張できる。
  - **MtG 艦艇設計**: 小型 (DD/CL) / 大型 (CA/BB/CV) / 潜水艦の船体 ×
    主砲・副砲 (火力・貫通) / 魚雷発射管 / 対空砲 / 爆雷 / 機関・ボイラー (速力・視界) /
    レーダー・ソナー (発見・対潜) / 飛行甲板 (艦載機数)。設計値は制海権 %・哨戒発見・
    潜水艦攻撃・退避速度へそのまま反映される。
  - **強襲上陸**: 経路の海域で自軍制海権 50% 以上が必要 (未満は上陸を拒否)。
  - **補給切れ**: 通商破壊で輸送船が枯渇 (実効輸入 < 25%) するか、任務海域の制海権が 25% 未満に
    なると貿易輸入が止まり、前線師団の組織力が毎日低下する (海軍ウィンドウに補給バナー表示)。

### マルチプレイの使い方

**将軍カードゲーム (`game/index.html`) のロビー**

1. ナビの **「マルチ」** を開き、**「ルームを作成（ホスト）」** を押す
2. 表示されたルームコード (`HOI4-8821` など) を **📋 コピー** して仲間へ送る
3. 仲間は **「ルームに参加（ゲスト）」** にコードを入力して **接続**
4. 各自の国家を選択 (ホストは他人の国家も割り当て可能) → ホストが **マルチプレイ開始**
5. 時間 (停止 / 速度) はホストが操作。ゲストは **⏸ 要請** で一時停止を要求できる

PeerJS (CDN) が使えない環境ではローカル通信モードになり、**同じブラウザの別タブ**で
`game/index.html` を開いて同じルームコードで参加すれば対戦できる。

**空軍 / 海軍ウィンドウ (BBA / MtG)**

1. 下部ナビの **「✈️ 空軍」「⚓ 海軍」** で管理ウィンドウを開く
2. 航空隊 / 任務部隊カードの **「🛠 設計」** から機体・艦艇を設計し「この設計を適用」
3. **「🎖 司令官」** から雇用済みの空軍将軍 / 提督カードを配置 (即時反映)
4. 空軍は **「🎯 空域を選ぶ」** で空域を指定すると、基地を中心に作戦半径円が描画される

**HOI4 単独ページ (`hoi4.html`) の時間同期**

```
# ホスト（時間の標準軸）
http://localhost:8000/hoi4.html?mp=host&room=room1
# クライアント（ホストへ時間同期）
http://localhost:8000/hoi4.html?mp=client&room=room1
```

## カードアセット（`game/card/`）

`game/card/manifest.json` を起点に `army/` `navy/` `air/` `mio/` 各ブランチの
JSONをロード。海軍/空軍の指揮官スロットには該当ブランチのカードのみ配属可能。
顔画像は `game/card/<TAG>/data/image/` および `game/assets/` の獲得済みアセットを使用。
