# 大戦略ゲーム — HOI4風グランドストラテジー UIシステム

Hearts of Iron IV 風の大規模戦略Webゲーム。Vanilla HTML5 / CSS3 / ES6 Modules（ビルド不要）。

## 起動方法

```bash
# 静的サーバー（リポジトリルートから）
python3 -m http.server 8000
# → http://localhost:8000/hoi4.html               HOI4 単独
# → http://localhost:8000/division-designer.html  師団編成 単独プレビュー
# → http://localhost:8000/game/                   将軍カードゲーム（H で HOI4 画面）

# マルチプレイ時間同期サーバー（別ターミナル）
node server/timesync-server.js 8787
```

エントリページは **リポジトリルートの `hoi4.html`**。すべてのアセットは厳密なパス
`game/assets/...`・`game/card/...`・`game/locales/ja.json` を参照する。

## 将軍カードゲーム（`game/index.html`）から HOI4 画面を開く

`game/index.html` に **「HOI4 大戦略」全画面レイヤー**を統合済み。カードゲームを
遊びながら、同じタブで HOI4 風の研究・生産・外交・戦闘画面へ切り替えられる。

| 起動方法 | 場所 |
| --- | --- |
| **H キー** | カードゲームのどこからでも（入力欄・IME 変換中を除く） |
| ナビゲーションレール | 「HOI4 大戦略」ボタン（`H` バッジ付き） |
| スタート画面 | 「🧭 HOI4 大戦略画面を開く（H）」 |
| 直接 URL | `game/index.html?screen=hoi4`（開いた状態で起動） |

- **Esc** または右上の「閉じる」でカードゲームへ戻る。HOI4 側の上部メニューにも
  「← 将軍カードゲーム」ボタンが出る（`?embed=1` のときだけ）。
- 選択中の国家タグが `?nation=GER` として引き継がれる（`GER/USA/ENG/SOV/JAP/ITA/FRA`）。
- iframe は初回オープンまで読み込まない。閉じても破棄しないため、HOI4 側の
  研究・生産などの状態は保持されたまま即座に再表示できる。
- 閉じている間は HOI4 の時間進行を自動で一時停止する（再表示で再開。
  ユーザーが自分で一時停止していた場合はそのまま）。
- `game/index.html?screen=hoi4` のように URL でも開ける。開閉時は `screen` パラメータだけを
  `history.replaceState` で付け外しする（他のクエリは保持）。

### なぜ iframe なのか

`hoi4.html` は `game/css/steel-ui.css` で `html` / `body` / `button` / `*` などの
グローバルスタイルを所有している。これをカードゲームの DOM に直接読み込むと
既存 UI の CSS を上書きしてしまうため、DOM・CSS・タイマーを完全に分離し、
`postMessage` で可視状態と「戻る」だけを連携している。

| ファイル | 役割 |
| --- | --- |
| `game/hoi4-screen.js` | 全画面レイヤー / 遅延 iframe / H・Esc / inert / URL 同期 / 国家引き継ぎ |
| `game/css/hoi4-screen.css` | スチール調クローム・ローディング・フッター・起動ボタン |
| `game/js/ui/embed.js` | `?embed=1` 時の親ページ連携（可視状態で時間停止 / Esc / ready 通知） |
| `game/js/ui/topbar.js` | 埋め込み時のみ「← 将軍カードゲーム」ボタンをメニュー末尾に追加 |

## 師団編成 / Division Designer（`J` またはメニュー「師団編成」）

陸軍管理の全画面デザイナー。トップバーの **「師団編成」** ボタン（`J`）で開閉する。
`U` の兵器設計/展開画面の「師団編成」タブからも全画面版を開ける。

| 位置 | 内容 |
| --- | --- |
| 左 | 師団テンプレート一覧（選択 / 新規作成 / 複製 / 削除）＋ 利用可能な大隊・支援中隊パレット |
| 中央 | 5×5 大隊グリッド ＋ 1×5 支援中隊スロット ＋ 訓練キュー |
| 右 | リアルタイム統計（対人/対装甲攻撃・突破・防御・貫通・装甲・硬度・組織力/組織率・戦闘幅・速度・補給・生産コスト・人的資源・訓練日数・必要装備） |

- **操作**: パレットで大隊を選びスロットをクリックで配置。同じ大隊の再クリック / 右クリック / `✕` で削除。
  パレット → スロット、スロット → スロットのドラッグ＆ドロップに対応（入れ替え可）。
  支援中隊は下段の 5 スロットのみ。消去モードあり。
- **リアルタイム再計算**: 配置・入替・支援中隊の変更ごとに `DivisionTemplate._recalc()` が走り、
  右パネルと「未保存の変更」差分（▲/▼）が即時更新される。
- **変更を保存**: `state.divisionTemplates` と `localStorage["hoi4.divisionTemplates.v1"]` に
  JSON を書き出し、以後の訓練・配備・装備所要量（`GameState.requiredEquipment()`）へ反映する。
- **訓練・配備**: 「この編成で訓練開始」で人的資源と装備を消費し、訓練キューへ追加。
  `GameState` の 1 時間 Tick で進行し、完了すると `state.divisions` に師団が配備される
  （`templateId` / `maxOrg` / `maxHp` / 攻撃力などのステータス付き）。訓練はキャンセルで資源返却。
- **単独プレビュー**: `division-designer.html` を開くと、モック状態でデザイナーだけを確認できる
  （デモ用の時間加速ボタン付き）。
- **テスト**: `node --test game/tests/division-designer.test.mjs`

## 空軍 / 航空隊・航空基地・空域任務（`A` または メニュー「空軍」）

HOI4 風の航空戦システム。**航空隊（Air Wing）** を航空基地へ配備し、**戦略空域**に任務を割り当てる。
制空権は「自軍 / 敵軍」の割合で表示され、CAS は進行中の地上戦へリアルタイムに反映される。

### 航空隊（機数 / 練度 / 稼働率）

| 項目 | 内容 |
| --- | --- |
| 機数 | 備蓄（`state.stockpile`）から機体を引き当てて編成。基地の空き容量まで |
| 練度（0-100） | 訓練任務で上昇（+0.9/時）。待機中は微減。実戦でも僅かに上昇 |
| 稼働率（0-100） | 出撃中は低下（-0.22/時、下限 30）、待機で回復（+0.55/時） |
| 戦力 | `機数 × (0.45+0.55×練度) × (0.45+0.55×稼働率)` |

機種は **戦闘機**（`fighter_equipment_1`）/ **近接航空支援機**（`tac_bomber_equipment_1`）/
**戦略爆撃機**（`strat_bomber_equipment_1`）。編成・移動・補充・解散が可能で、
移動すると稼働率が -10 される。

### 航空基地（州ごと Lv0-5）

| Lv | 収容 | 基準工期 |
| --- | --- | --- |
| 1 | 100 機 | 45 日 |
| 2 | 200 機 | 65 日 |
| 3 | 300 機 | 85 日 |
| 4 | 400 機 | 105 日 |
| 5 | 500 機 | 125 日 |

- 建設は通常の建設キュー（民需工場）に積まれ、空き民需工場で進捗速度が変わる。
- 建設できる場所：①マップで自国州をクリック → 州パネルの「建設」ボタン
  ②`T` 建設画面の州カード「航空基地」行 ③空軍画面の航空基地一覧
- 航空基地 Lv0 の州には航空隊を配備できない。首都は初期状態で Lv3。

### 戦略空域と制空権

- 空域は 5 つ（西ヨーロッパ / 東ヨーロッパ / 地中海 / 東アジア / 北アメリカ）。
- `制空権 = 自軍戦力 / (自軍戦力 + 敵軍戦力)`。敵航空戦力は空域ごとの基準値
  （例: 西ヨーロッパ 300）に戦時補正（×1.15）を掛けたもの。
- マップを **空軍モード** にすると空域円・自軍/敵軍の割合バー・航空隊アイコンを表示。
  **空域円をクリックすると制空権ウィンドウ**（自軍/敵軍の割合、任務内訳、CAS 支援、空域内の州）が開く。
- 状態色：65% 以上 = 優勢（緑）/ 45〜64% = 均衡（黄）/ 45% 未満 = 劣勢（赤）。

### 任務（Mission）

| 任務 | 効果 |
| --- | --- |
| **制空**（Air Superiority） | 制空権への寄与 100%。敵戦闘機との消耗戦で損失が出る |
| **近接航空支援**（CAS） | 制空権寄与 35%。射程内（CAS 機 1,000km）の**戦闘中の州**へ攻撃力ボーナス（最大 +30%）と直接ダメージ |
| **戦略爆撃**（Strategic Bombing） | 制空権寄与 20%。敵州のインフラ・工場・航空基地を破壊 |
| **訓練**（Training） | 制空権寄与 40%。練度が上昇し、戦闘には参加しない |

- 射程は機種ごと（戦闘機 1,500km / CAS 1,000km / 戦略爆撃機 2,600km）。
- 損失は `機数 × 機種消耗率 × 敵制空権割合 × 任務リスク` で毎時発生する。

### CAS の戦闘連動（`battle-plan.js`）

```
groundPower = Σ (CAS 機の戦力 × 対地攻撃力)
contested   = 0.45 + 0.55 × 自軍制空権割合        // 制空権が低いと効果減
bonus       = min(0.30, groundPower / 1600 × contested)   // 攻撃力 +30% まで
damage      = min(9, groundPower / 320 × contested)       // 防御側の組織力/HPへ毎時直接ダメージ
```

- 戦闘バブルに ✈ マーカーが付き、ツールチップに CAS ボーナス・与ダメージ・参加機数が出る。
- 戦闘ログ／バブルは `battle.cas`（`bonus` / `damage` / `aircraft` / `wingCount`）を保持する。

### 戦略爆撃

- 6 時間ごとに、任務空域内の敵州（VP が最も高い州）へ爆撃を行う。
- 被害は 2 系統で蓄積：施設被害 100% で**インフラ → 航空基地**の順に 1 段階破壊、
  工場被害 100% で**工場**を 1 つ破壊（`state.industry`）。
- 破壊は `air-bombing` イベントで通知され、`state.airBombings` に履歴（最大 40 件）が残る。

### 保存

`localStorage["hoi4.airWings.v1"]` に航空基地レベルと航空隊（機数・練度・稼働率・任務）を保存する。

## 補給網 / インフラ・補給ハブ（`T` → 「州インフラ・補給網」タブ / `F2`）

HOI4 風の補給システム。州ごとの **インフラ（0〜5）** と **補給ハブ（0〜3）** を建設し、
首都から鉄道網を伝って補給を流す。容量を超えた州の師団は移動速度・戦闘力・組織率が低下する。

### 建設（建設画面の「州インフラ・補給網」タブ）

| 建物 | 最大Lv | 基準工期（現Lv基準） | 効果 |
| --- | --- | --- | --- |
| インフラ | 5 | 70 + 14×Lv 日 | 現地調達量 +0.8/Lv、ハブのスループット係数 +0.09/Lv |
| 補給ハブ | 3 | 120 + 45×Lv 日 | 補給源。スループット (4 + 5×Lv)、到達範囲 2+Lv 州 |

資源コストは消費せず、民需工場の稼働で進む（既存の建設キューと共通）。

- 首都は自動的に **Lv3 の補給ハブ** を持つ（建設不要）。インフラも最大で開始。
- 建設は `state.constructionQueue` に積まれ、`economy.tick()` で進行 →
  完成時に `SupplyManager.completeConstruction()` が州のレベルを+1 して再計算する。
- **建設スロット**: 1州あたり同時 **3 件** まで。同じ州で同じ建物の二重予約は不可。
- 建設速度は空き民需工場数に応じて `0.5〜1.5倍`（`0.5 + 空き民需×0.12`）で変動する。
- 予約・キャンセルはカード/全国キューの `✕` から。キャンセルで予約枠が空く。
- 同じ州カードには **航空基地（Lv0-5）** の建設行も表示される（空軍システムと建設キューを共有）。

### スループット計算（`SupplyManager.recompute()`）

```
hubThroughput = (4 + 5×hubLv)
              × (0.55 + 0.09×ハブ州インフラLv)
              × (0.50 + 0.10×経路上の最小インフラLv)
              × (首都ハブなら 1.1)
到達範囲     = 2 + hubLv 州（PROVINCE_LINKS の隣接グラフ、首都から幅優先）
距離減衰     = 0.55^距離
州の容量     = インフラLv×0.8（現地調達） + 最も強い1つのハブからの供給量
```

- 経路は首都 →（鉄道網）→ 各補給ハブ。マップの補給モードで **点線アニメーション** として描画。
- ハブは重複加算しない（1州につき最良の1ハブのみ）。首都が無い/孤立している国は
  最高VP州を仮の補給源にする。

### 師団ペナルティ（`supplyPenalties(ratio)`）

| 比率 `ratio = 容量 / 需要` | 状態 | 移動速度 | 戦闘力 | 組織率上限 |
| --- | --- | --- | --- | --- |
| ≥ 1.0 | 正常（緑） | 100% | 100% | 100% |
| ≥ 0.5 | 不足（黄） | 70〜100% | 65〜100% | 70〜100% |
| < 0.5 | 枯渇（赤） | 40〜70% | 30〜65% | 40〜70% |

- `speed = 0.40 + 0.60×ratio` / `combat = 0.30 + 0.70×ratio` / `org = 0.40 + 0.60×ratio`
- 毎 Tick（1時間）`SupplyManager.tick()` が各師団へ
  `supplyRatio` / `supplyPenalty` / `effectiveMaxOrg` を書き込み、
  組織力は `effectiveMaxOrg` を上限に切り下げられる。補給が足りると 0.5/時 で回復。
- `battle-plan.js` はこの値を使い、進軍所要時間に `/ speed`、攻撃力に `× combat` を適用する。

### マップ表示（`F2` または「補給」ボタン）

- 州の塗りは **緑 = 正常 / 黄 = 不足 / 赤 = 枯渇**。薄い州は自国領外。

## 諜報機関 / スパイ活動（`Shift+W` または メニュー「諜報機関」 / マップ `F3`）

HOI4 風の **諜報機関（Intelligence Agency）** システム。政治力（PP）で機関を設立し、
エージェントを雇って敵国へ派遣する。ネットワークが育つほど対象国の情報が「透けて見える」。

### 機関の設立とアップグレードツリー

機関の設立には **政治力 50**。設立すると本部 Lv1 とエージェント枠 2（初代エージェント 1 名つき）を得る。

| ブランチ | 最大Lv | 費用（PP） | 効果 |
| --- | --- | --- | --- |
| **機関本部**（`hq`） | 3 | 60 / 90 / 130 | エージェント枠 +1/Lv、基礎インテル +3/Lv（他ブランチの前提） |
| **暗号解読チーム**（`crypto`） | 3 | 50 / 75 / 110 | 解読速度 +25%/Lv、軍事情報の閾値 -6/Lv、`暗号解読支援` 解禁（Lv1〜） |
| **政府への潜入**（`infiltration`） | 3 | 45 / 70 / 100 | ネットワーク構築 +4/Lv、政治閾値 -5/Lv・経済閾値 -4/Lv |
| **特殊部隊**（`special_forces`） | 2 | 75 / 120 | `破壊工作`・`技術窃取` 解禁（Lv1）、`クーデター支援` 解禁（Lv2）、成功率 +12%/Lv |

いずれも **本部 Lv1 が前提**。強化は「機関」タブのカードから行う。

### エージェントの雇用と任務

- 雇用費 **政治力 40**。枠（`1 + 本部Lv`）を超える雇用はできない。技能（諜報長 / 言語学者 /
  破壊工作員 / 暗号技術者 など）と技能値で所要日数と効果が変わる。
- 任務は「エージェント」タブで **対象国 + 任務** を選んで指示する。進捗は残り日数で表示。

| 任務 | 基準日数 | 効果 |
| --- | --- | --- |
| **ネットワーク構築**（`build_network`） | 30 日 | ネットワーク +18（潜入 Lv で加算） |
| **プロパガンダ**（`propaganda`） | 36 日 | 対象国の安定度 -6 / 戦争協力度 -8、インテル +6 |
| **暗号解読支援**（`decrypt`） | 21 日 | インテル +12、解読 +1（軍事情報の解禁が早まる・暗号解読 Lv1〜） |
| **破壊工作**（`sabotage`） | 45 日 | 工場 -20%（30 日間・特殊部隊 Lv1〜） |
| **技術窃取**（`steal_tech`） | 60 日 | 研究ボーナス 12%（特殊部隊 Lv1〜） |
| **クーデター支援**（`coup`） | 90 日 | 成功率 35% + 特殊部隊 Lv×6%（特殊部隊 Lv2〜） |

所要日数は技能とブランチで短縮される（例: 暗号解読は `÷ (1 + 0.25 × crypto Lv)`）。

### インテルレベルと情報優位

```
intelLevel = network × 0.62 + intelPoints × 0.55 + decrypted × 6 + base   // 0-100 に clamp
base       = 2 + hq_Lv × 3 + crypto_Lv × 2        （機関未設立なら 0）

政治情報 ≥ max(8,  20 - infiltration_Lv × 5)
経済情報 ≥ max(18, 45 - infiltration_Lv × 4 - crypto_Lv × 3)
軍事情報 ≥ max(32, 70 - crypto_Lv × 6 - infiltration_Lv × 2)
```

| 段階 | 見える情報 |
| --- | --- |
| 政治情報 | イデオロギー / 指導者 / 安定度 / 戦争協力度 / 政治力 |
| 経済情報 | 民需・軍需・造船の工場数 / 輸送船 / 人的資源 |
| 軍事情報 | 推計師団数・即応度・**州ごとの師団配置（推計）** |

- 「インテル」タブに対象国（主要 7 か国から自国を除く）ごとのカードを表示。
  未解禁の行は 🔒 と「インテル XX 以上で解禁」を出す。
- 軍事情報が解禁されると **「師団配置をマップで見る」** からマップを諜報モードへ切り替えられる。

### マップ表示（`F3` または「諜報」ボタン）

- 首都に **ネットワーク進行度リング**（インテル段階の色：政治=黄 / 経済=青 / 軍事=赤）とインテル値を表示。
- 軍事情報を得た国は、州ごとに **敵師団配置バッジ**（兵科記号 + 推計師団数）を重ねる。
  数値は「軍需工場 × 0.6 + 民需工場 × 0.3」から算出し、州の VP 比で配分した **推計値**。
- ヘッダーの「敵師団の表示: ON/OFF」で切り替え（`state.intel.showEnemyForces` に保存）。
- マーカーをクリックすると諜報画面が開く。

### 保存

`localStorage["hoi4.intelAgency.v1"]` に機関（ブランチ Lv）・エージェント（任務）・
ネットワーク・インテル値・解読数・履歴・表示フラグを保存する。

### テスト

```bash

```

## 主要システム

- **統一スチールフレームUI**: 全モーダルが金属フレーム＋リベット＋金文字タイトル＋閉じるボタン。
  3D金属ボタン / LEDインジケーター / インセット型入力フィールド。
- **トップバー**: 最上段ステータスバー（国旗Q・政治力・安定度・戦争協力度・徴兵可能人口・
  工場数・燃料残日数・装備充足率LED・輸送船 / 指揮力・陸海空XP・核弾頭）＋2段目メニュー。
- **研究**: `game/eng/tec/data/tech_*.json`（294ノード）を読み込み、国家別補正で独自研究日数を算出。
  Tickでカウントダウン。MIOアサインで研究加速。
- **MIO**: 研究/生産完了でXP蓄積→レベルアップ（最大Lv5）→3段階の特性ツリーを選択。
- **師団設計**: 5×5大隊グリッド＋1×5支援中隊。全ステータスを配置と同時に再計算。
- **兵器設計**: 戦車（車体＋主砲/砲塔/懸架/エンジン/装甲/特殊）、艦艇（船体＋主砲/対空/魚雷/ソナー/
  レーダー/機関/装甲）、航空機（機体＋エンジン/武装/特殊）。
- **増槽（Drop Tank）**: 航続距離+75%〜100% / 機動性-10% / 生産コスト+15%。
  航空機設計タブで装着するとマップ上に出撃可能半径を円表示。
- **戦闘シミュレーター**: 攻撃側/防御側の編成・地形・天候・戦術・指揮官・掘り込みを設定し、
  1Tick（1時間）ごとにダイスロール戦闘。組織力/HPバーのアニメーション＋日本語戦闘ログ。
- **諜報機関**: 政治力で機関を設立し、本部 / 暗号解読チーム / 政府への潜入 / 特殊部隊の
  4 系統をアップグレード。エージェント（`game/assets/operatives/` 肖像）を敵国へ派遣して
  ネットワーク構築・プロパガンダ・暗号解読・破壊工作・技術窃取・クーデター支援を実行。
  ネットワーク進捗とインテル値が閾値を超えると対象国の政治 → 経済 → 軍事情報が解禁され、
  軍事情報ではマップに敵師団配置（推計）が透けて見える（`Shift+W` / マップ「諜報」/ `F3`）。
- **占領地・傀儡国**: 占領度が2週間ごとに+3%。100%で「国家統一」（併合・コア化）ボタン。
- **空軍（航空隊）**: 戦闘機/CAS/戦略爆撃機を航空基地（州 Lv0-5・100 機/Lv）へ配備し、
  制空・近接航空支援・戦略爆撃・訓練の任務を空域へ割り当て。制空権は自軍/敵軍の割合で表示し、
  CAS は進行中の地上戦の攻撃力・与ダメージへリアルタイムに反映される（`A` キー）。
- **マルチプレイ時間同期**: HOSTのTickを標準軸に `TIME_SYNC_TICK` を全Clientへ配信。
  一時停止/倍速もブロードキャスト。遅延時はCatch-up補正。
  - 同一ブラウザの別タブ間: BroadcastChannel で同期（サーバ不要）
  - クロスデバイス: WebSocket（`server/timesync-server.js`、既定ポート8787）

### マルチプレイの使い方

