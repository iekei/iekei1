# プロヴィンス単位の面的バトルプラン

対象は `game/index.html` の将軍カードゲーム。別エントリの `hoi4.html` は変更しません。

## 操作

1. 軍集団へ師団を配属します。
2. 「前線を引く」または既存の国境自動指定で前線を設定します。師団は自国陸路を1区画ずつ進んで担当地点へ移動します。
3. 「攻撃線を引く」または Shift+右ドラッグで、**敵領内の到達したい目標ラインに沿って**なぞります。従来の「前線から敵へ1本の矢印を引く」操作ではありません。
4. 「計画実行」。各師団が独立して隣接区画へ進み、異なる区画で並列に戦闘します。
5. 中止すると、その軍集団の並列戦闘をすべて解除し、現在の区画に駐留します。前線や目標線の描き直しは中止後に行います。

緑は実際の自国・敵国プロヴィンス境界、赤の破線と区画輪郭は目標線です。軍集団パネルに目標区画数・現在の前線区画数・並列戦闘数を表示します。単に目標線を描くだけでは攻撃を開始しません。

## 実装

### 地形グラフと境界

`MapRenderer.buildAdjacency()` が隣接を双方向で登録します。元の片方向登録では同じ国境を逆向きに移動できない場合がありました。

同じピクセル走査から `MapRenderer.provinceBoundarySegments` を作り、共有する区画境界の座標を保存します。前線はこの実境界を Canvas へ描画し、離れた区画の中心を最近傍順で結ぶ線は使用しません。横方向の地図ラップには地図両端の境界を登録します。

### 面的な計画

`assets/area-battle-plan.js` の `AreaBattlePlan` が通常の陸上計画を担当します。

- `offensiveLine.pids` は目標となる複数区画。矢印の方向ベクトルではありません。
- 始点群・目標群のBFS距離場から、計画に含まれる有限のプロヴィンス集合（`corridor`）を計算します。
- Manhattanグラフの「同距離の経路を全部足すと矩形になる」問題を避けるため、グラフ上の中心経路からの距離と始点・終点の幅で許可範囲を補間します。進行先は常に隣接グラフで選び、ベクトル移動はしません。
- 最初の幅は指定した前線から始めます。到達・占領した区画を `activated` に追加して前線を拡張するため、狭い始点から幅広い目標へ即座に前線が飛ぶことはありません。
- 各師団に目標を分配し、距離と区画の混雑を考慮して次の隣接区画を選びます。目標を確保した師団は計画内の残りの敵区画へ再配分します。
- 自国領内の行軍は1区画/24ゲーム時間。初期配備や隙間埋めでもテレポートしません。敵領への移動は戦闘勝利後のみです。
- 中立国・海・接続していない飛び地を横断しません。目標国との和平時は計画と進行中の区画戦闘を停止します。

`army.arrow` は既存UI・セーブとの互換メタデータとしてのみ残しています。通常攻勢は `army.route`、州単位の `chain`、軍集団の代表点のベクトルを使用しません。旧セーブの一点目標は新しい一点収束型の計画へ移行します。強襲上陸・空挺の特殊処理は引き続き従来の専用処理です。

### 並列戦闘

`BattleManager.startOffensive(..., {divisionIds})` は参加師団の実在・隣接・所有権・二重参加を検証します。

- 同じ軍集団から複数プロヴィンスで同時戦闘できます。
- 戦力、組織力減少、装備損耗、占領後の移動は参加師団だけに適用します。
- 敗北はその参加師団だけを24時間の再編待ちにし、他区画の戦闘は継続します。
- 一つの目標区画につき戦闘は一件。別軍集団の戦闘への合流・多方向支援は本変更には含みません。
- 中止済み・解決済みの戦闘結果を再適用しません。

占領のたびに計画ごとの前線境界を再計算します。他国との全世界の国境へ軍集団を自動転送したり、前線の隙間へ瞬間移動させたりしません。

### 保存

計画は `army.areaPlan`、担当・行軍待ち・再編待ちは師団の `plan*` フィールド、戦闘参加者は `battle.divisionIds` / `originPids` に保存します。既存の軍集団・戦闘JSON保存に含まれます。距離場のMap/SetはWeakMapキャッシュにのみ置き、セーブの読み込み後に再構築します。

## 検証

```sh
node --test game/tests/*.test.cjs game/tests/*.test.mjs
```

追加した `game/tests/area-battle-plan.test.cjs` は16件。分散攻撃、参加者単位の移動・損耗、拡幅・収束、他正面との分離、中立国・水域、配備時の隣接移動、和平、中止、結果の再適用防止、セーブ復元、描画境界、実ドラッグハンドラーを検証します。共通VMフィクスチャは `game/tests/helpers/strategy-fixture.cjs` です。

ヘッドレスChromiumでも `game/index.html` を実際に起動し、ドイツの実地図で12師団・3目標区画の計画を検証しました。戦闘勝利を固定したシミュレーションで計画地域の確保・完了、移動ごとの隣接性、Canvas描画を確認しています。これは本家HoI4と同じ戦闘バランスや全地形での戦術的最適性を保証するものではありません。
